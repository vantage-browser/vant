# Vantage Browser v0.1.1

Vantage Browser v0.1.1 improves desktop integration and everyday browser
interaction. It adds fullscreen and application-window launch modes, draggable
tabs with reordering and cross-window movement, desktop launcher actions for new
and private windows, stricter command-line validation and persistent website
sessions.

This release also repairs address-bar suggestion focus, navigation text
corruption, website login input, tab drag feedback and detaching tabs into new
windows when they are dropped outside Vantage.

Vantage is Linux-first preview software. It does not provide Chromium or Firefox
extensions, browser-account sync, or an independent rendering engine. WebKitGTK
provides web rendering and the core web security model.

Install from the immutable tagged source release with:

```sh
curl -fsSL https://vant.cx/install.sh | sh
```
